### English
# ImportPonyJS 🐎
- **Import your PTC skins on the main server!** ✨  

---

## 🌟 Key Features  
1. **🎨 Pony Import**  
   - One-click import of custom skins, supporting PTC/TXT formats

2. **🌐 Cross-Browser Compatibility**  
   - Supported by ScriptCat 🐱 / Tampermonkey 🐵 extensions
   - Compatible with Edge 🟣 / Chrome 🟡 / Firefox 🔴

---

## 📦 How to Use  
1. **🔧 Install the Extension**
   - ScriptCat / Tampermonkey → Search for "PonyTownImportPony" → Click Install Script → Success! 
   -  Or open [ImportPony](https://ponyjs.lonel.uno/ImportPony/) → Click Install → Success!
1. **🐎 Import Ponys** 
   - Open edit character → Click the Import button → Select file → Success!
